INTERVIEWER TIPS

      

        
Green Flags

        
    
          
  • Asks clarifying questions: "What's the threat model? What compliance requirements?"
    • 
          
  • Prioritizes by blast radius, not by line number
    • 
          
  • Connects issues across modules
    • 
          
  • Proposes systemic fixes, not point fixes
    • 
          
  • Mentions tools: tfsec, checkov, Terraform Cloud, Infracost, OIDC
    • 
        

      

      

        
Red Flags

        
    
          
  • Reads sequentially from line 1 instead of scanning
    • 
          
  • States that something is wrong but not why
    • 
          
  • No mental model for multi-environment Terraform
    • 
          
  • Cannot discuss IAM beyond "it needs permissions"
    • 
          
  • Fixates on cosmetic issues while missing security gaps
    • 
        

      

      

        
Calibration

        
    
          
  • Don't penalize missing Tier 3 issues if they nail architecture
    • 
          
  • Phase 3 is weighted highest intentionally
    • 
          
  • Finding every bug but no state management strategy = no pass
